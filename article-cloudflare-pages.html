Deploying a static site to Cloudflare Pages: the 10-minute setup

If your site is plain HTML, CSS, and a little JavaScript — like this one — Cloudflare Pages is the fastest way to get it live for free, with a global CDN and automatic HTTPS out of the box.

Option A: drag-and-drop deploy (fastest)

  1. Sign in to the Cloudflare dashboard and open the Workers & Pages section.
  2. Choose Create application → Pages → Upload assets.
  3. Drag your site folder in (the one containing index.html) and confirm.
  4. Cloudflare gives you a live *.pages.dev URL within seconds.

Option B: connect a Git repository (best for ongoing updates)

  1. Push your site folder to a GitHub or GitLab repository.
  2. In Cloudflare Pages, choose Create application → Pages → Connect to Git.
  3. Select the repo. Since this is a plain static site, leave the build command empty and set the output directory to / (the project root).
  4. Every future push to your main branch redeploys automatically.

Connecting your own domain

Once the site is live on a *.pages.dev address, go to your Pages project's Custom domains tab and add your domain. If the domain's DNS is already on Cloudflare, this is usually a one-click step; otherwise you'll add a CNAME record pointing to your Pages project.

Keep the site "light" on purpose: no build step, no framework, no database. Fewer moving parts means fewer things that can break on a free static host.

A few things worth doing before you launch

  • Add a proper 404.html so broken links don't dead-end visitors.
  • Compress images before uploading — Cloudflare Pages doesn't optimize them for you.
  • Set up Cloudflare's free Web Analytics instead of a heavier tracking script.
  • Double check every affiliate link works and opens in a way that's clearly disclosed to readers.

That's genuinely the whole setup — no server to manage, no monthly hosting bill for a site this size.
